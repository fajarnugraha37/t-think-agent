# Critique Policy

## Human critique is input, not truth

A critique may reveal a real defect, a partial misunderstanding, an unverified production fact, or a preference unrelated to model correctness. The agent must separate these cases.

## Safe response shape

For each critique, record:

1. target;
2. reviewed evidence;
3. supporting findings;
4. contradicting findings;
5. alternative interpretations;
6. classification;
7. falsification condition;
8. revision or investigation action.

## No private chain-of-thought requirement

The package requires a concise structured rationale, not hidden token-by-token reasoning.
