# Routing rules

- Missing or contradictory evidence → `INVESTIGATION`.
- Invalid system model → `SYSTEM_MODEL`.
- New semantic decision or invalid solution semantics → `SOLUTION_DESIGN`.
- Invalid or incomplete human solution approval → `SOLUTION_CRITIQUE`.
- Changed problem meaning → `PROBLEM_ALIGNMENT`.
- Plan-only correction → `IMPLEMENTATION_PLAN`.
- Fully resolved and human-approved package → `IMPLEMENTATION_CHECKLIST`.
