# Routing rules

- `EVIDENCE_GAP` or unresolved repository behavior → `INVESTIGATION`
- `MODEL_CONFLICT` → `SYSTEM_MODEL`
- `SEMANTIC_DECISION_REQUIRED`, `SOLUTION_CONFLICT`, or semantic scope expansion → `SOLUTION_DESIGN`
- invalid/missing human approval → `SOLUTION_CRITIQUE`
- plan decomposition defect only → remain in `IMPLEMENTATION_PLAN`
- complete and internally consistent → `PLAN_CRITIQUE`
