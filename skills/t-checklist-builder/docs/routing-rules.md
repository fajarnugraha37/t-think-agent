# Routing Rules

- Missing or contradictory evidence → `INVESTIGATION`.
- Incorrect system model → `SYSTEM_MODEL`.
- New or changed solution semantics → `SOLUTION_DESIGN` or `SOLUTION_CRITIQUE`.
- Invalid human plan approval or approved-plan contract → `PLAN_CRITIQUE`.
- Ambiguous, incomplete, or non-atomic plan operation → `IMPLEMENTATION_PLAN`.
- Checklist-only formatting/decomposition defect → remain in `IMPLEMENTATION_CHECKLIST`.
- Fully reconciled atomic bundle → `CHECKLIST_CRITIQUE`.
