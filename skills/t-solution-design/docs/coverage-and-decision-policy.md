# Coverage and Decision Policy

Every active option must have one coverage row for each design target. `FULL` means the option contains a concrete mechanism and verification strategy that fully addresses the target. `PARTIAL` must state the unaddressed remainder. `NONE` must explain why the option leaves the target unresolved.

At least one viable option must fully cover every target required as `FULL`. An option may be recommended, but the recommendation is non-binding. The decision record must remain `DRAFT` or `UNDER_CRITIQUE`; human selection occurs in a later phase.
