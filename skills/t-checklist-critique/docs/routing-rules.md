# Routing Rules

- Mechanical checklist defect: `IMPLEMENTATION_CHECKLIST`.
- Invalid or stale plan approval: `PLAN_CRITIQUE`.
- Ambiguous or incomplete plan operation: `IMPLEMENTATION_PLAN`.
- Missing actual evidence: `INVESTIGATION`.
- Model defect: `SYSTEM_MODEL`.
- New semantic choice: `SOLUTION_DESIGN` or `SOLUTION_CRITIQUE`.
- Problem misunderstanding: `PROBLEM_ALIGNMENT`.
- Fully resolved and human-approved: `BOUNDED_IMPLEMENTATION`.
