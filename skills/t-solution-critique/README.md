# Solution Critique Skill Package

Ready-to-use, evidence-gated Solution Critique phase for the governed AI engineering lifecycle.

## Install
```bash
python -m pip install -r validators/requirements.txt
```

## Validate the included transition-ready example
```bash
make validate-example
```

## Run tests
```bash
make test
```

## Package validation CLI
See `validators/validate.sh --help` or `python validators/validate.py --help`.
