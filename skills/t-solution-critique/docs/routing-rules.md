# Routing rules

- Missing or contradictory actual evidence: return to `INVESTIGATION`.
- Approved model is invalidated: return to `SYSTEM_MODEL`.
- Problem meaning or expected outcome changes: return to `PROBLEM_ALIGNMENT`.
- Option, coverage, dominance, recommendation, or decision record needs revision: return to `SOLUTION_DESIGN`.
- Review complete but human has not selected or approved: remain in `SOLUTION_CRITIQUE`.
- Human-approved, viable, fully covering solution contract: continue to `IMPLEMENTATION_PLAN`.
